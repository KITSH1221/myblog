Rust三层库

层级 依赖 提供内容
core 零依赖 Option，Result，原子操作，基本类型
alloc 需要全局分配器 Vec，String，Box，Arc
std 依赖操作系统 文件，网络，线程,println!
  • #[no_std]=只使用core，放弃std and alloc
  • os内核，嵌入式,Bootloader,WebAssembly

从空文件到可运行程序

.cargo/config.toml
[build]
rustflags=[“-C”,”link-args=nostartfiles”]

Bump allocator

  • std 中 format!(“{}”, 42) → String → malloc → brk/mmap → 内核
  • no_std 中没有 malloc，需要提供 malloc
  • 特点:极快的O(1),但不能释放
  • 场景:Bootloader,Arena,短生命周期

内存对齐

  • 对齐公式: (offset+align-1)&!(align-1)实现向上取整
